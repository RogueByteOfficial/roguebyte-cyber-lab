# Contributing to RogueByte Cyber Lab

Thank you for your interest in contributing to **RogueByte Cyber Lab**!

## How to Contribute
1. Fork the repository from [RogueByteOfficial/roguebyte-cyber-lab](https://github.com/RogueByteOfficial/roguebyte-cyber-lab) or [sidopac1a/roguebyte-cyber-lab](https://github.com/sidopac1a/roguebyte-cyber-lab).
2. Create a descriptive feature branch: `git checkout -b feature/new-lab-template`.
3. Follow the coding guidelines (TypeScript, strict typing, Tailwind CSS, zero console warnings).
4. Run automated tests before submitting: `npm test` and `npm run lint`.
5. Ensure that any new lab templates enforce `internal: true` network isolation and safe resource caps (`mem_limit: 512m`).
6. Submit a Pull Request with a clear description of your changes.

## Code of Conduct
Please be respectful, ethical, and collaborative. All educational exercises must strictly serve defensive and authorized ethical penetration testing goals.
